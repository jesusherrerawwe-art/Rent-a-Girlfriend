## 4. Decisiones de estilo

1. **Diálogos con comillas inglesas** (" "), por pedido de Chuy. Su computadora no lee los guiones largos.
2. **Sin guiones largos (—) ni medios guiones (–) en la prosa.** Para las pausas se usan comas, dos puntos, puntos suspensivos o paréntesis.
3. **Capítulos de ~5,200 palabras.** Se permite que se extiendan si la escena lo pide.
4. **Diálogo ~70%, descripción breve.** La descripción es visual e impresionista: dos o tres líneas para anclar la escena.
5. **Capítulo = mini-episodio.** Gancho, giro, cierre con pregunta.
6. **Primera persona con voz.** Jesús narra con humor de autodefensa; no se compadece de sí mismo. El dolor se cuenta con objetos, no con adjetivos.
7. **Nada de exposición.** Lo que el lector necesita saber se muestra en escena o se deja en documentos.
